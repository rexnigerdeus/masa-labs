Premiers pas
Comment créer un compte Rondo ?
  1. Téléchargez l'app Rondo sur l'App Store.
  2. Sur l'écran d'accueil, appuyez sur « S'inscrire ».
  3. Saisissez votre numéro de téléphone (ex : +225 07 XX XX XX XX).
  4. Choisissez un mot de passe (6 caractères minimum).
  5. Donnez votre prénom et nom.
  6. Appuyez sur « Créer mon compte ». Vous êtes connecté·e immédiatement.

Aucun email à vérifier, aucun code SMS à saisir. L'inscription prend moins de 30 secondes.

Comment créer une tontine ?
  1. Sur la page d'accueil, appuyez sur le bouton « + Nouvelle tontine ».
  2. Donnez-lui un nom (ex : « Famille Koné »).
  3. Définissez la mise par tour (ex : 10 000 FCFA).
  4. Choisissez la fréquence : hebdomadaire ou mensuelle.
  5. Indiquez le nombre de membres attendu (modifiable après).
  6. Fixez la date de démarrage du premier tour.
  7. Appuyez sur « Créer ».

Votre tontine est créée. Rondo génère automatiquement un code d'invitation à 6 chiffres et un lien partageable.

Comment inviter des membres à rejoindre ma tontine ?

Depuis l'écran Détail de la tontine, appuyez sur « Inviter ». Vous avez deux options :

  • Code d'invitation : un code à 6 chiffres que vos membres saisissent depuis l'écran d'accueil (bouton « Rejoindre une tontine »).
  • Lien de partage : un lien que vous pouvez copier et envoyer directement par WhatsApp, SMS ou email. Le membre est redirigé vers l'app et rejoint automatiquement.
Comment rejoindre une tontine avec un code ?
  1. Sur l'écran d'accueil, appuyez sur « Rejoindre une tontine ».
  2. Saisissez le code à 6 chiffres fourni par l'administrateur.
  3. Vérifiez les informations de la tontine (nom, mise, fréquence).
  4. Appuyez sur « Rejoindre ».
Puis-je faire partie de plusieurs tontines ?
Oui, c'est l'un des principes de Rondo. Une seule personne peut gérer plusieurs tontines différentes, être membre dans plusieurs autres, etc. Aucune limite en v1.0.
Paiements
Comment enregistrer un paiement ?

Seul l'administrateur d'une tontine peut enregistrer les paiements :

  1. Ouvrez la tontine concernée.
  2. Appuyez sur « Enregistrer un paiement ».
  3. Sélectionnez le membre qui a cotisé.
  4. Saisissez le montant (par défaut, la mise du tour).
  5. Choisissez le mode de paiement : Espèces, Wave ou Orange Money.
  6. Ajoutez une note optionnelle (ex : « Reçu par WhatsApp le 12/07 »).
  7. Appuyez sur « Confirmer ».

Le membre reçoit immédiatement une notification de confirmation, et un reçu PDF est généré automatiquement.

Les paiements Wave et Orange Money sont-ils intégrés ?

En v1 (version actuelle), Rondo enregistre et trace les paiements (espèces, Wave, Orange Money) avec leur mode, leur date et un reçu PDF. L'intégration directe avec les API Wave / Orange Money pour déclencher le paiement depuis l'app est prévue pour la v2.

Concrètement aujourd'hui : votre admin reçoit l'argent (en main propre, via Wave, via Orange Money) et note le paiement dans Rondo. L'app s'occupe du reste : notification au membre, reçu, mise à jour de la cagnotte.

Comment fonctionne le reçu PDF ?

À chaque paiement enregistré, Rondo génère automatiquement un reçu PDF qui contient :

  • Le nom de la tontine
  • La date et le montant du paiement
  • Le nom du membre qui a cotisé
  • Le mode de paiement (espèces / Wave / Orange Money)
  • Le numéro du tour
  • La signature de l'administrateur

Le membre reçoit le PDF par notification et peut le télécharger ou le partager depuis l'écran « Mon historique ».

Que se passe-t-il si un membre est en retard ?

Rondo vous alerte automatiquement à plusieurs niveaux :

  • J-3 avant la date : notification push au membre lui rappelant la cotisation à venir.
  • Date dépassée : le statut du membre passe à « En retard » et un badge rouge apparaît dans la liste.
  • J+2 : notification à l'administrateur pour le prévenir.

Aucune sanction automatique n'est appliquée : Rondo informe, c'est à l'administrateur et au groupe de décider des suites.

Puis-je corriger ou annuler un paiement ?

Oui, dans les 24 heures suivant l'enregistrement, l'administrateur peut modifier ou supprimer un paiement depuis l'écran « Historique ».

Au-delà de 24h, la modification est bloquée pour garantir l'intégrité de l'historique du groupe. Si une correction est nécessaire, contactez-nous à support@everyday.co avec le numéro de tontine, et nous étudierons la modification au cas par cas.

Compte
J'ai oublié mon mot de passe. Comment le réinitialiser ?
  1. Sur l'écran de connexion, appuyez sur « Mot de passe oublié ? ».
  2. Saisissez votre numéro de téléphone.
  3. Appuyez sur « Envoyer le code » — vous recevez un code à 6 chiffres par SMS (frais opérateur appliqués par votre forfait).
  4. Saisissez le code reçu et définissez un nouveau mot de passe.

Si vous ne recevez pas le SMS, attendez 60 secondes et réessayez, ou contactez-nous à support@everyday.co.

Puis-je changer mon numéro de téléphone ?

Oui. Allez dans Paramètres → Profil → « Modifier mon numéro ». Saisissez votre nouveau numéro, validez-le par le code SMS reçu, et le tour est joué. Toutes vos tontines et données restent associées à votre compte.

Comment supprimer définitivement mon compte ?

Allez dans Paramètres → Compte → « Supprimer mon compte ». Cette action est irréversible :

  • Toutes vos tontines administrées sont supprimées.
  • Vous êtes retiré·e de toutes les tontines dont vous étiez membre.
  • Vos données personnelles sont effacées de nos serveurs sous 30 jours.

Si vous êtes le seul admin d'une tontine avec d'autres membres, ceux-ci devront en choisir un nouveau avant la suppression.

Confidentialité & sécurité
Mes données sont-elles en sécurité ?

Oui. Toutes vos données sont :

  • Chiffrées en transit (HTTPS / TLS 1.3)
  • Chiffrées au repos sur nos serveurs (chiffrement AES-256 côté base de données)
  • Hébergées en Europe (Supabase, conforme RGPD)
  • Sauvegardées quotidiennement avec rotation sur 30 jours
Rondo collecte-t-il des données sur moi ?

Rondo collecte uniquement ce qui est nécessaire au fonctionnement de l'app :

  • Votre numéro de téléphone (identité unique, jamais partagé)
  • Votre prénom et nom (affichés aux autres membres de vos tontines)
  • Votre photo de profil (optionnelle, jamais partagée en dehors de vos tontines)
  • L'historique de vos tontines

Rondo ne collecte PAS : vos contacts, votre localisation, votre appareil photo, votre micro, vos données bancaires, votre historique de navigation. Jamais.

Pourquoi un pseudo-email avec mon numéro de téléphone ?

C'est un détail technique lié à notre choix d'infrastructure Supabase. Pour des raisons de compatibilité technique, votre identifiant interne est techniquement un email de la forme {numéro}@everyday.co.

Cela ne change rien pour vous : aucun email n'est jamais envoyé, aucun email n'est jamais demandé. Votre identité reste votre numéro de téléphone. C'est purement un identifiant technique.

Mes tontines sont-elles visibles par d'autres utilisateurs ?

Non. Vos tontines ne sont visibles que par :

  • Vous (administrateur ou membre)
  • Les membres de chaque tontine (qui ne voient que les tontines dont ils font partie)
  • L'administrateur de chaque tontine (qui voit tous les détails)

Personne d'autre, jamais. Même notre équipe support n'a accès au contenu de vos tontines, sauf demande explicite de votre part pour un dépannage.
